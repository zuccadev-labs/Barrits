## Editorial Standards

- This area is intended for maintainers and architects. It focuses on the "how" and "why" of the implementation.
- All documentation follows a formal third-person corporate tone.
- Files must be kept in sync with the corresponding Spanish (`ES`) documentation to ensure bilingual parity.
