# 06 Bun Integration

The Bun example highlights the SDK's compatibility with high-performance runtimes and rapid development cycles.

## Features

- **Fast Dev Workflow**: Leveraging Bun's native performance for rapid file discovery and manifest generation.
- **Runtime Consistency**: Certification that the `ts_js` core behaves identically in the Bun environment compared to Node.js.
- **Minimal Configuration**: Showing how to get up and running with Barrits using Bun's native task runner and dependency manager.

## Usage Scenarios

This example is ideal for:
- High-speed development environments where iteration time is critical.
- Microservices designed for the Bun runtime.
- Prototyping complex domain graphs with immediate feedback.
