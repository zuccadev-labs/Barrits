# 00 TS/JS Examples Index

This directory provides a curated collection of integration examples categorized by runtime, framework, and usage patterns. These examples serve as both a learning resource and a functional validation surface for the SDK.

## Example Categories

1.  **[01-general-map.md](01-general-map.md)**: High-level overview of all available examples and their directory structure.
2.  **[02-nodejs-and-deno.md](02-nodejs-and-deno.md)**: Core server-side and CLI orchestration in Node.js and Deno environments.
3.  **[03-frontend-vite.md](03-frontend-vite.md)**: Modern frontend integration using React, Vue, Solid, and Svelte via Vite.
4.  **[04-bundlers.md](04-bundlers.md)**: Integration with esbuild, Rollup, and Webpack build pipelines.
5.  **[05-tauri.md](05-tauri.md)**: Secure desktop application development with Tauri.
6.  **[06-bun.md](06-bun.md)**: High-performance execution and dev-mode workflows with Bun.

## Usage Guidelines

- Each example is a standalone project that demonstrates a specific consumption scenario.
- All examples link back to the main [API Reference](../09-api-reference.md) rather than duplicating technical details.
- To run an example, navigate to its directory under `packages/sdk/ts_js/examples/` and follow the instructions in its local `README.md`.
