# 00 Examples index for ts_js

I use this folder to document the executable examples of the SDK without overloading the short package README or each local example README.

Reading order:

1. `01_overview.md`: I explain how `packages/sdk/ts_js/examples/` is organized.
2. `02_nodejs-and-deno.md`: I document the pure runtime journeys for Node.js and Deno.
3. `03_frontend-vite.md`: I document the package-first frontend examples with React, Vue, Solid, and Svelte.
4. `04_bundlers.md`: I explain when I use `bundlers/` instead of a runtime example.
5. `05_tauri.md`: I document the secure desktop example with a Tauri backend and summarized artifact consumption.

Reading rule:

- I enter this folder first when I want to decide which example to open.
- I only drop into the local example README after I know which flow I want to run.
- The source code remains the final operational reference.
