# Agent Skills for Barrits

This directory contains AgentSkills-compatible skills for framework-level usage patterns and release operations in this repository.

## Location

Skills are stored in `docs/agents/skills/<skill-name>/SKILL.md`.

## Included Skills

- `barrits-package-first-implementation`
- `barrits-cross-runtime-validation`
- `barrits-release-orchestration`

## Notes

- Each skill includes YAML frontmatter (`name`, `description`) and actionable workflows.
- Descriptions are written for model-triggering intent and remain concise.
- Skills prioritize deterministic commands and non-interactive execution.
